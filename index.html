KNOWLEDGE BASE

Fundamentos de rede

Entenda algumas das tecnologias que fazem a internet funcionar.

01 / IPv4

192.168.1.1

O IPv4 é a quarta versão do Protocolo de Internet. Utiliza endereços de 32 bits para identificar dispositivos e redes.

Ele permite aproximadamente 4,3 bilhões de endereços diferentes.

02 / IPv6

2001:db8::1

O IPv6 é uma versão mais moderna do protocolo IP. Utiliza endereços de 128 bits.

Sua enorme capacidade de endereçamento ajuda a atender à crescente quantidade de dispositivos conectados.

03 / DNS

google.com → endereço IP

DNS significa Domain Name System. Ele traduz nomes de domínio em endereços IP, facilitando o acesso aos sites.

Sem precisar decorar sequências numéricas, podemos acessar serviços usando nomes.

Você sabia? / Dual Stack

Dual Stack é uma configuração de rede que permite utilizar IPv4 e IPv6 simultaneamente.

Assim, um dispositivo pode se comunicar com serviços que utilizam qualquer um dos dois protocolos.

Privacidade e segurança

Esta página apresenta os endereços retornados pelos serviços de consulta. Ela não envia os resultados para um terminal ou banco de dados próprio. Os serviços externos utilizados podem registrar suas próprias requisições.
